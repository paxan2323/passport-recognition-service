# Хотфикс-план — экран чата поддержки (/messages)

> Для AI-агента. Дата: 2026-07-05. Дополнение к `EXECUTOR_CHAT_AND_FEEL_PLAN.md` (этап A3
> реализован, но с дефектами вёрстки и рудиментом «Помощь»). Скоуп — только экран /messages;
> архитектуру чата (optimistic, офлайн-очередь, вложения, пагинация) не трогать — она работает.

---

## ДИАГНОЗ (факты из кода)

**Д1. Двойной скролл и «пустая глубина» страницы.** Три вложенных контейнера конфликтуют:

| Слой | Код | Проблема |
|---|---|---|
| Page-scroll shell'а | `shell.tsx` (обёртка всех табов) + `messages-screen.tsx:219` `<div className="space-y-4 pb-36">` | Внешний скролл страницы + 9rem мёртвого паддинга снизу |
| Контейнер чата | `chat-tab.tsx:300` `minHeight: calc(100dvh - 12rem)` | Растягивает чат на весь экран даже с 1 сообщением |
| Лента сообщений | `chat-tab.tsx:331` `maxHeight: calc(100dvh - 16rem)` + `overflow-y-auto` | Второй (внутренний) скролл; константы 12/16rem не согласованы ни между собой, ни с реальной высотой H1+сегментов |

Итог: с одним сообщением страница скроллится «в пустоту» на высоту (minHeight − maxHeight) + pb-36;
лента живёт своим скроллом; сообщения прижаты к верху, композер — к низу, между ними дыра.
Дополнительно: `V2PullToRefresh` обёрнут вокруг чата — жест тянет страницу, конфликтуя со
скроллом ленты; `pb-4` ленты не учитывает реальную высоту fixed-композера (при заполненном
треде последнее сообщение уходит под композер).

**Д2. Вкладка «Помощь» циклична.** При включённом чате её primary-кнопка —
«Написать менеджеру в чате» → соседний таб (`help-screen.tsx:27-30`). Сегмент из двух
вкладок, где вторая отправляет в первую.

**Д3. Шапка.** Три заголовка подряд: H1 «Сообщения» → сегмент-бар → identity-хедер чата.
Fallback имени — «Менеджер» с подписью «менеджер» (`chat-tab.tsx:156` — дубль).

**Д4. Мелочи.** Инциденты дорисовываются хвостом после всех сообщений, вне хронологии
(`chat-tab.tsx:377`); mark-read выполняется один раз за маунт (`markedReadRef` блокирует
отметку сообщений, пришедших пока чат открыт); quick-чипы `flex-wrap` — при трёх чипах
композер занимает три строки.

## ЦЕЛЕВАЯ РАСКЛАДКА (одна, без магических rem)

Чат — **полноэкранный flex-столбец между верхом экрана и таб-баром**, страница не скроллится вообще:

```
┌──────────────────────────────────┐
│ [М] Мария · менеджер        [⚠]  │  header (в потоке, не fixed)
│──────────────────────────────────│
│                                  │
│  лента: flex-1 overflow-y-auto   │  ЕДИНСТВЕННЫЙ скролл экрана
│  первый ребёнок: margin-top:auto │  ← контент прижат к НИЗУ (как в мессенджерах)
│         · 5 июля ·               │
│              [Уже в пути 16:50 ✓]│
│──────────────────────────────────│
│ [Уже в пути][Опаздываю][Есть во…]│  чипы: одна строка, overflow-x-auto
│ [📎][ Напишите…            ][➤]  │  композер: В ПОТОКЕ flex-столбца (не fixed)
│──────────────────────────────────│
│  Сегодня · Смены · Деньги · Проф │  таб-бар
└──────────────────────────────────┘
Высота: flex через inset-контейнер (top:0 → bottom: tabbar+safe-area),
клавиатура: паддинг снизу = visualViewport inset (хук уже есть).
```

Ключ: композер внутри flex-столбца → не нужны ни `position:fixed`, ни расчёт его высоты,
ни `pb-36`, ни обе `calc(100dvh - N rem)`. Прокручивается только лента; при малом числе
сообщений они лежат у композера, сверху пусто (нормально для чата), скроллить нечего.

## ЗАДАЧИ

### CF-1 · Однослойная раскладка чата — приоритет 1
- **Файлы:** `chat-tab.tsx`, `messages-screen.tsx`, точечно `shell.tsx` (opt-out паддинга).
- Чат-таб рендерится в контейнере `fixed inset-x-0 top-0 bottom-[tabbar+safe]` (по образцу
  live-экрана) ИЛИ shell даёт вариант «fullBleed» для этого роута — выбрать одно, не городить оба.
- Убрать: `minHeight`/`maxHeight`-магию, `position:fixed` композера, `pb-36` страницы на чат-табе.
- Лента: `flex-1 overflow-y-auto`, первому ребёнку `margin-top: auto` (прижатие к низу);
  автоскролл к низу при новом сообщении — сохранить; подгрузка ранних при scrollTop<40 — сохранить.
- `V2PullToRefresh` на чат-табе отключить (SSE + poll 30s покрывают; жест конфликтует).
  На вкладках объявлений/инцидентов — оставить.
- Клавиатура: паддинг-низ композера = `useVisualViewportInset` (хук уже подключён — перенести
  с fixed-bottom на padding).
- **DoD:** с 1 сообщением экран не скроллится вообще (нечему); с 200 — скроллится только лента,
  последнее сообщение никогда не перекрыто композером; открытие клавиатуры не прячет композер
  (проверить iOS Safari + Android Chrome); скриншоты 360×740 пусто/1 сообщение/полный тред.

### CF-2 · Снести вкладку «Помощь» из /messages — приоритет 1
- **Файлы:** `messages-screen.tsx`, `help-screen.tsx`, `profile-screen.tsx`.
- Сегмент «Чат | Помощь» убрать. Правило то же, что на «Сменах»: один таб = нет сегмент-бара.
  (Объявления/инциденты, когда включены, остаются сегментами — их контент не циклится.)
- FAQ-контент переезжает: пункт «Помощь» в профиле ведёт на `/profile/help` (или секцию
  профиля до перехода на под-роуты) с FAQ + телефон диспетчера. Кнопку «Написать менеджеру
  в чате» там оставить — из профиля она не циклична.
- В шапке чата (⋯ или «?») — вход в ту же помощь BottomSheet'ом, опционально.
- При **выключенном** `direct_messages`: /messages рендерит help-контент напрямую, без табов
  (как сейчас, но без сегмента из одной вкладки).
- **DoD:** из чата нельзя попасть на экран, чья главная кнопка возвращает в чат; помощь
  доступна из профиля за ≤2 тапа; deep-link `/messages?tab=help` редиректит на новое место.

### CF-3 · Шапка чата — приоритет 2
- **Файлы:** `messages-screen.tsx`, `chat-tab.tsx`.
- На чат-табе H1 «Сообщения» не рендерить — identity-хедер чата и есть заголовок
  (высвобождает ~7rem). На вкладках объявлений/инцидентов H1 остаётся.
- Fallback имени: «Поддержка» без подписи-роли; caption «менеджер» — только при реальном
  `sender_name`. Убрать дубль «Менеджер/менеджер».
- **DoD:** над лентой ровно один заголовочный блок; скриншот «пустой чат» без дубля слов.

### CF-4 · Инциденты в хронологию — приоритет 2
- **Файлы:** `chat-tab.tsx`.
- Слить карточки инцидентов в общий список по `created_at` (тип-union message|incident),
  а не хвостом после сообщений. Разделители дат учитывают оба типа.
- **DoD:** инцидент от 3 июля стоит между сообщениями 3 июля, не после сегодняшних.

### CF-5 · Мелочи композера и прочтения — приоритет 3
- Quick-чипы: `flex-nowrap overflow-x-auto` одной строкой (высота композера постоянна).
- Mark-read: снять `markedReadRef`-блокировку — отмечать прочитанными новые manager-сообщения,
  пришедшие пока чат открыт (эффект по изменению списка unread-id, с дедупликацией).
- Textarea: авто-рост до 4 строк вместо фиксированных `rows={2}`.
- **DoD:** бейдж unread гаснет для сообщений, полученных в открытом чате; чипы не переносятся.
