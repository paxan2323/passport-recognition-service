## 0. Контекст продукта

- **Продукт:** white-label PWA для исполнителей (курьеры, сборщики, мерчендайзеры) на платформе «Гермес».
- **Тестовый стенд:** `https://test-org.executor.app.shift.hermes-support.ru/` (тенант `test-org`, пустые данные).
- **Стек фронта:** Next.js (App Router), Tailwind CSS v4, shadcn-стиль токенов (`--background`, `--card`, `--border`, `--primary` и т.д.), Sonner (тосты), date-fns (ru), Lucide-иконки. PWA: manifest, shortcuts («Мои смены», «Отметиться», «Заработок»), web push.
- **API (наблюдаемое):** `GET /api/executor/v1/slots/?page&page_size`, `GET /api/executor/v1/me/`, `GET /api/executor/v1/tenant-info/`, `GET /api/executor/v1/wallet/`, `GET /api/executor/v1/esign/`, `GET /api/executor/v1/events/` (**long-poll**, держит соединение), `POST /api/executor/v1/auth/refresh/`.
- **Маршруты сейчас:** `/login`, `/slots` (+`?period=today|tomorrow|all`, `?view=calendar`), `/slots/[id]`, `/earnings`, `/inbox`, `/profile`, `/profile/security`, `/documents` → redirect `/profile?tab=documents`.
- **Мультитенантность:** `tenant-info` отдаёт `terminology_map` (worker=Исполнитель, slot=Слот, penalty=Штраф…), `primary_color` (`--brand-primary`, дефолт `#5b5bd6`, у test-org `#4f46e5`), `auth_providers` (`direct_phone`, `mango_waitcall`), `password_policy`, и **78 фичефлагов** (`features`): qr_checkin, shift_breaks, open_shift_pickup, shift_swap, shift_bidding, worker_availability, time_off, shift_ratings, proof_of_work, expense_reimbursement, npd, rocket_work, dispatch_map, announcements, direct_messages, incident_reports, contextual_reliability, discipline_points, user_locale, offline_mode, single_slot_per_day, shift_leader, counters и др.
- **Уже реализовано на бэке/в коде фронта** (строки найдены в бандлах): чекин/чекаут, подтверждение выхода, перерывы, «Опоздаю» (+ETA мин), «Не выйду» (+причина), бронь/снятие брони, QR-сканер + ручной код локации, офлайн-очередь отметок («Ожидает синхронизации: N», «Синхронизировать»), отчёт о смене с обязательным фото, оспаривание штрафа, инциденты (типы: Безопасность/Оборудование/Клиент-объект/Расписание/Другое; статусы Открыт/В работе/Решён/Закрыт/Отклонён), объявления, чат с диспетчером, e-sign, passkey/WebAuthn, сессии устройств, PWA-инсталл-промпт, push-промпт, coach-marks, тёмная тема, крупный текст.

## 1. Цель

Полный редизайн UX/UI приложения исполнителя. Бизнес-логика и API сохраняются, интерфейс проектируется заново. Целевое качество — уровень Uber Driver / Wolt Courier / Яндекс Про.

**Три вопроса, на которые любой экран отвечает за 3 секунды:**
1. Что мне делать сейчас? (одна кнопка-состояние)
2. Сколько я заработал? (деньги видны всегда)
3. Всё ли в порядке? (документы/синк/сообщения как задачи)

## 2. Жёсткие ограничения (нарушать нельзя)

1. Не менять контракты API; новые данные (ставка на карточке слота, дата выплаты) — через расширение ответов, согласовать отдельно.
2. Сохранить white-label: цвета от `--brand-primary` тенанта, все термины — через `terminology_map`.
3. Каждый блок/раздел рендерится **только при включённом фичефлаге**; выключенная фича не оставляет пустых оболочек и мёртвых табов.
4. Offline-first: любой экран проектировать сначала в состоянии «офлайн + пустые данные». Отметки работают из очереди.
5. Доступность: контраст AA, touch-цели ≥ 48px, режим «Крупный текст» сохранить.
6. Тексты — «партнёрский» тон, без канцелярита и админского словаря (см. §6).

## 3. Новая навигация и карта экранов

Нижний таб-бар (mobile) / левый рейл (desktop ≥1024):
**Сегодня · Смены · Деньги · Профиль**. Таб «Связь» удаляется: чат — иконка в шапке (бейдж), уведомления+объявления — Центр сообщений под колокольчиком.

```
/login  → телефон → OTP(WebOTP)/waitcall/пароль/passkey; заявка на регистрацию + статус-трекер
/       → «Сегодня»: hero-карточка смены, деньги кратко, задачи, свободная смена рядом
/shifts → сегмент «Мои | Свободные»; недельная полоска; лента по дням
/shifts/[id] → деталка; полноэкранный live-режим активной смены
/money  → hero «К выплате» + дата; график; лента смен; /money/[id] деталка; выплаты-таймлайн
/messages → центр сообщений (события, объявления, чат)
/profile → хаб: Документы, Подписи, Надёжность, Доступность, Снаряжение, Настройки, Безопасность, Помощь
```

## 4. Ключевые экраны — спецификация

### 4.1 «Сегодня» (главный, новый)
- Шапка: дата + «Доброе утро, {имя}»; справа колокольчик (бейдж) и чат; тихий индикатор офлайна («Сохранено · отправим при сети»).
- **Hero-карточка** (самый крупный элемент) — state-машина одной кнопки:
  `не подтверждена → «Выйду на смену»` · `>2ч до начала → «Маршрут · выходить к HH:MM»` · `на точке → «Я на месте» (гео/QR)` · `идёт → live: таймер, ≈заработано, Перерыв` · `конец → слайдер «Отметить уход»` · `закрыта → «+N ₽» + оценка`.
  Вторичные действия — иконки: маршрут, чат, «Опоздаю».
- Метрики: «Неделя · N ₽», «Смен · X из Y».
- Карточки-задачи (по необходимости): паспорт/документ/подпись/несинхронизированные отметки — одна карточка = одно действие.
- «Свободная смена рядом» (флаг open_shift_pickup): 1 рекомендация, оплата крупно, «Забрать» + undo.
- Пустое состояние: следующая свободная смена + CTA «Найти смену» + заработок недели.

### 4.2 Смены
- Убрать: табы Сегодня/Завтра/Все, тумблер Календарь/Список, кнопку «Обновить список», штамп «Обновлено HH:MM».
- Добавить: недельная полоска (7 дней, точки-смены, свайп; тап по месяцу → сетка), лента с группировкой по дням, сегмент «Мои | Свободные».
- Карточка слота: статусная полоса 3px слева, время крупно, локация, **ставка**, одна контекстная кнопка. Статусы словами: «Ждёт подтверждения», «Вы записаны», «Идёт · 3:12», «Закрыта · +3 240 ₽», «Отправится при сети».
- «Свободные»: фильтры (дата, время суток, локация, ставка), сортировка «выгоднее/ближе», бронь в 1 тап + snackbar-undo.

### 4.3 Активная смена (live-режим, новый)
Полноэкранный, тёмный: таймер (tabular-nums 32px) + прогресс-бар; «Заработано ≈ N ₽» live; кнопки Перерыв/Задания/Чат; «Проблема на точке? Сообщить» (инцидент за 2 касания); внизу слайдер «Проведите — отметить уход». Чекин: приоритет геозоны, QR fallback, ручной код — последний.

### 4.4 Деньги
Hero «К выплате N ₽» + «Выплата в {день}»; бары по дням (прогноз забронированных — пунктиром); лента смен: `+N ₽` зелёным / штраф `−N ₽` красным с причиной и «Оспорить» (флоу спора: причина+фото → трекер «Отправлено → На рассмотрении → Решение»); деталка смены: часы план/факт, ставка, надбавки, штрафы, компенсации; выплаты — таймлайн «Начислено → В обработке → Выплачено»; экспорт PDF/CSV в меню «···». Кошелёк из профиля удаляется (объединение).

### 4.5 Профиль
Хаб: крупная карточка (аватар, имя, статус, рейтинг/стрик по флагам) + пункты-подэкраны. Документы: карточки со сроками, цвет по близости истечения, push за 14/3 дня; загрузка через камеру с маской + OCR-автозаполнение. E-sign: bottom-sheet, прочтение → «Подписать». Гейты аккаунта («На проверке», «Отклонено», «Нужны документы») — полноценные экраны со статусом, следующим шагом и контактом менеджера.

### 4.6 Вход
Телефон (автоформат) → SMS-код с WebOTP — путь по умолчанию. Waitcall: крупный номер, кнопка «Позвонить» (tel:), автопроверка каждые 3с, текст «Звонок бесплатный, сбросится сам». Passkey предложить после первого входа. Ошибки с действием («Номер не найден → Подать заявку»).

## 5. Дизайн-система 2.0

- **Цвет (семантические токены):** `bg #F6F7F9 · surface #FFF · text #16181D · muted #697086 · brand var(--brand-primary) · money/success #0F766E · warning amber · danger #DC2626 · info blue`. Тёмная тема авто + тумблер; live-режим всегда тёмный.
- **Типографика:** Inter variable; tabular-nums для денег/таймеров; шкала Display 32/40, Title 22/28, Headline 17/24, Body 15/22, Caption 13/18, Micro 11/16; «Крупный текст» = +2 ступени.
- **Радиусы:** sm 8 · md 12 · lg 16 · xl 20 · pill 999. **Spacing:** шаг 4, поля 16/24. **Размеры:** primary-кнопка 56px full-width (одна на экран), поле 52px, таб-бар 64px+safe-area, touch ≥48px.
- **Компоненты (все состояния: default/pressed/focus/disabled+причина/loading/error/success/offline):** AppBar, TabBar, HeroShiftCard, SlotCard, StatusPill (точка+пилюля 8% фона), MoneyStat, TaskCard, BottomSheet (все подтверждения — sheet, не модалки), SlideToConfirm, ChipsPresets, Timeline, ChatBubble, OfflineBanner, EmptyState (иллюстрация+1 CTA), Skeleton, Toast+undo, QRScannerOverlay, PhotoUploader (камера-первый).
- **Моушен:** 150–250мс ease-out; каунт-ап денег; конфетти на закрытии смены/выплате; haptics на чекин/чекаут; skeleton вместо спиннеров.

## 8. Definition of Done (каждой задачи)

1. Работает на 360×640 и 1440×900; таб-бар/рейл корректны.
2. Все состояния компонента реализованы, включая offline и пустые данные.
3. Фичефлаг выключен → блока нет совсем (не заглушка).
4. Термины — из `terminology_map`; цвета — из токенов (ноль хардкода hex в компонентах).
5. Контраст AA; touch ≥48px; работает «Крупный текст».
6. Скриншоты до/после в PR; метрика этапа не деградирует (LCP < 1.5s).

## 9. Что запрещено

## 10. Метрики успеха

- «Открыл → отметился» < 5 сек; конверсия подтверждения выхода +20%.
- Тикеты «когда выплата / что со статусом» −50%; no-show −30% (этап 3).
- LCP < 1.5s; retention D30 +20%; оценка в сторах ≥ 4.6.
